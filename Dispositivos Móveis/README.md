## 📌 Sobre a Disciplina

Este diretório armazena os estudos, atividades práticas e projetos desenvolvidos durante a disciplina de programação para dispositivos móveis. O foco principal dos estudos foi o desenvolvimento de aplicações nativas e multiplataforma utilizando **Flutter** e **Dart**.

---

## 🛡️ Projeto Final: Terminal Tático S.H.I.E.L.D.

O grande destaque prático desta disciplina foi o desenvolvimento de uma aplicação completa consumindo uma API externa (SuperHero API). O projeto, inicialmente um catálogo de personagens da Marvel, foi transformado em uma experiência imersiva simulando um **Terminal de Inteligência Tática da S.H.I.E.L.D.**

### 🔗 Acesso ao Código-Fonte
Para manter a organização e o controle de versão focados na aplicação, o código completo do projeto final está hospedado em um repositório dedicado.

**Acesse o repositório oficial da aplicação aqui:**  
👉 [**Projeto-marvel-shield**](https://github.com/viniciuzxd/Projeto-marvel-shield.git)

### Principais Conceitos Aplicados no Projeto:
* Construção de Interfaces (UI/UX) com estética *Cyber-HUD*.
* Gerenciamento de Estado nativo (`ValueNotifier`, `FutureBuilder`).
* Consumo e parse de APIs REST via HTTP.
* Renderização de gráficos customizados (`CustomPainter`).
* Persistência de dados locais (`SharedPreferences`).
